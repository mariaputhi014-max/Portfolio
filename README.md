> A modern, animated, dark-mode personal portfolio website built with HTML5, CSS3, and JavaScript featuring glowing neon accents, 3D tilt cards, interactive particle canvas, and Samsung One UI-inspired audio waveforms.

---

## ✨ Features

- 🌌 **Dark Neon Cyber Aesthetic**: Deep dark canvas (`#0a0a0f`) illuminated with electric blue (`#00f0ff`), neon purple (`#b829ff`), and neon pink (`#ff2e93`).
- ⚡ **Interactive Constellation Canvas**: HTML5 2D canvas particle network that connects and reacts to cursor interaction.
- 🎛️ **Audio Waveform Stand Lines**: Samsung One UI media player-inspired squiggly sine waveforms along the footer and vertical education timeline with real-time scroll progress tracking.
- 🌊 **Flanking Side Wave Runners**: Dual full-height vertical waveforms framing the left and right flanks of the viewport.
- 🔮 **Animated Profile Frame**: Circular avatar with counter-rotating conic-gradient rings, expanding radar pulse waves, orbiting glowing satellites, and holographic scanline sweeps.
- 🃏 **3D Perspective Tilt Cards**: Project showcase cards that dynamically calculate mouse coordinates for 3D tilt physics and dynamic radial sheen.
- 📜 **Vertical Education Timeline**: Milestones tracking B.Sc. in CSE at AIUB, HSC, and SSC.
- 📱 **Fully Responsive**: Optimized for ultra-wide monitors, laptops, tablets, and mobile smartphones with slide-in navigation drawer.
- 📄 **Curriculum Vitae**: Integrated downloadable CV (`cv.pdf`).

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Custom Variables, Flexbox/Grid, Keyframe Animations, Glassmorphism), Vanilla JavaScript (ES6+)
- **APIs & Observers**: HTML5 Canvas API, Intersection Observer API, matchMedia API
- **Icons & Fonts**: Font Awesome 6, Google Fonts (*Space Grotesk*, *Poppins*, *Fira Code*)

## 🚀 Getting Started

To run this portfolio locally:

```bash
# Clone the repository
git clone https://github.com/mariaputhi014-max/Portfolio.git

# Navigate to the project directory
cd Portfolio

# Start a local HTTP server
python -m http.server 3000
```

Then open [http://localhost:3000](http://localhost:3000) in your web browser.
